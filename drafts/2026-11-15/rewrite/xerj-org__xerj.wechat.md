# 工具是手段，判断是本事

> 先弄清 xerj 管什么，再决定用不用。

一个工具值不值得装，先看它能不能给你留下点能直接用的东西。今天说个能自己试试的小工具。

## 它是什么

xerj 是 GitHub 上的一个开源项目，用 Rust 写，19092 人收藏，采用 Apache-2.0 协议。作者自己写的介绍放在项目页面，点进去能看见。

## 能带走的三条

- 不用 match 的实现
- html / txt / md 格式支持
- 离线可用

## 怎么装

安装命令写在项目说明里，复制下来跑一遍就行。动手前去项目页面扫一眼，作者可能改过版本。
