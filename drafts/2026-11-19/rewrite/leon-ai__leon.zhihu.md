## 先做哪一步

```
# Clone the repository
git clone https://github.com/leon-ai/leon.git

# Go to the project root
cd leon

# Install pnpm
npm install --global pnpm@latest

# Install dependencies
pnpm install

# Run Leon
pnpm start
```

命令是仓库说明里现成的，动手前扫一眼项目页面，作者可能改过版本。
