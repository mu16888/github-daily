# 省下的那一步，代价在哪

> rea-video 是干什么的，先看结论。

看项目说明最容易漏掉的不是功能列表，是装完之后第一步做什么。先给结论，再看怎么弄。

## 它是什么

rea-video 是 GitHub 上的一个开源项目，用 Python 写，13820 人收藏，采用 Apache-2.0 协议。作者自己写的介绍放在项目页面，点进去能看见。

## 能带走的三条

- 不用 video 的实现
- md / json / html 格式支持
- 离线可用

## 怎么用

项目说明里没给能复制的安装命令，它更像一份要照着写的约定。说明里分了几块，去项目页面按顺序看就行。

说明里没有可复制的命令，先把看得懂的部分用起来就行。
