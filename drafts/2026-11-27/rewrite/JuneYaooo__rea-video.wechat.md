# 先定边界，再谈 rea-video

> 先弄清 rea-video 管什么，再决定用不用。

一个工具值不值得装，先看它能不能给你留下点能直接用的东西。今天说个能自己试试的小工具。

## 它是什么

rea-video 是 GitHub 上的一个开源项目，用 Python 写，13820 人收藏，采用 Apache-2.0 协议。作者自己写的介绍放在项目页面，点进去能看见。

## 能带走的三条

- 不用 video 的实现
- md / json / html 格式支持
- 离线可用

## 怎么用

项目说明里没给能复制的安装命令，它更像一份要照着写的约定。说明里分了几块，去项目页面按顺序看就行。

话题：#开发工具# #开源# #效率工具#
标签：agent-skills,ai-video,aigc-detection,开发工具,开源

这类东西的价值在约定本身，不在装了什么。用之前先把说明读一遍。
