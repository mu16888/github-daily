# 先定边界，再谈 kiri

> 先弄清 kiri 管什么，再决定用不用。

同样的活儿换个做法，省下来的往往不是时间，是反复确认的功夫。今天说个能自己试试的小工具。

## 它是什么

kiri 是 GitHub 上的一个开源项目，用 Rust 写，12136 人收藏，采用 Apache-2.0 协议。作者自己写的介绍放在项目页面，点进去能看见。

## 先记这几点

- 三端一套代码
- 12136 Star

## 怎么装

安装命令写在项目说明里，复制下来跑一遍就行。动手前去项目页面扫一眼，作者可能改过版本。
