# md / txt / yaml 格式支持，这个工具能干啥

看项目说明最容易漏掉的不是功能列表，是装完之后第一步做什么。先给结论，再看怎么弄。

## 它是什么

hermes-webui 是 GitHub 上的一个开源项目，用 Python 写，19488 人收藏，采用 MIT 协议。作者自己写的介绍放在项目页面，点进去能看见。

## 能带走的三条

- 不用 build 的实现
- md / txt / yaml 格式支持
- 离线可用

## 怎么装

安装命令写在项目说明里，复制下来跑一遍就行。动手前去项目页面扫一眼，作者可能改过版本。
