改一遍和每次都改，是两回事。说明里给了几条能直接用的。

## 它是什么

> Open source agentic operating system

主要用 **TypeScript** 写，GitHub 上攒了 **19905** 颗星（就是收藏数），用的是 MIT 协议。仓库地址：[elizaOS/eliza](https://github.com/elizaOS/eliza)。

## 前后差在哪

- md / json / txt 格式支持
- 19905 Star

## 先跑这条

```
git clone --filter=blob:none https://github.com/elizaos/eliza.git
cd eliza
bun install
bun run dev
```

命令是仓库说明里现成的，动手前扫一眼项目页面，作者可能改过版本。
